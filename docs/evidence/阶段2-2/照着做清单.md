# 阶段 2-2 验收：照着做

## 1. 启动

```bash
cd backend
.venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8020
```

浏览器打开 <http://127.0.0.1:8020/>。

## 2. 发起变更

点左侧「变更演示：隔离 core-sw-01 的 Gi1/0/24」，等 8–10 秒。

看变更卡片是否包含：资产、动作、参数、理由、影响面、回滚方式、plan_hash，以及「批准 / 拒绝」按钮。

## 3. 批准并执行

点「批准」。预期：
- 出现「已批准（approval…）」；
- 自动执行并回读，卡片状态变为「已回读验证」；
- 回复里明确说「模拟」，不声称碰了真实设备。

## 4. 看审计

点右上角「审计」：
- 能看到 change.proposed / approved / executing / executed / verified；
- 顶部显示「哈希链校验通过（N 条）」。

## 5. 验证安全边界（可选）

- 直接问我「帮我下电 core-sw-01」：应被策略拒绝；
- 批准后不要重复点批准；重复执行应被拒（一次性审批）。

## 6. 打分

把体验填到 `样例打分.md`；哪条不能接受直接说。
