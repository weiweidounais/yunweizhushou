# 阶段 3-2 验收：照着做

## 启动

```bash
# 终端 1：后端
cd backend
.venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8020

# 终端 2：前端
cd frontend
npm run dev
```

打开 <http://localhost:3010/>。

## 变更闭环

1. 左侧点「变更演示：隔离 core-sw-01 的 Gi1/0/24」→ 发送；
2. 等 6–12 秒，出现诊断 + **变更计划**卡片：
   - 资产、动作、参数、理由、影响面、回滚、plan_hash；
   - 状态「待审批」，有「批准 / 拒绝」；
3. 点「批准」：
   - 按钮消失，卡片变「已批准」；
   - 自动执行 + 回读，出现新卡片「已回读验证」；
   - 执行/回读摘要明确标「模拟」。
4. 点卡片里的「查看审计记录」或顶部「审计」：
   - 看到 change.proposed/approved/executing/executed/verified；
   - 顶部「哈希链校验通过 共 N 条」。
5. 手机 390 宽：变更卡片和批准按钮可点，审计表可横向滚动。

## 本阶段不包含

- 刷新后变更卡片恢复（3-3；审计记录保留）；
- SSE、取消/重试完整交互（3-3）；
- 真实设备执行（始终是模拟执行器）。

## 验收

没问题回「验收通过」；卡片字段、审批手感、审计表要改直接说。
