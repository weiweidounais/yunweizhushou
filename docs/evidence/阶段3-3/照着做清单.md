# 阶段 3-3 验收：照着做

## 启动

```bash
# 终端 1
cd backend && .venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8020
# 终端 2
cd frontend && npm run dev
```

打开 <http://localhost:3010/>。

## 最近会话

1. 左侧「最近会话」列出历史，点任意一条切换；
2. 当前会话高亮；手机 390 宽点左上角菜单，抽屉里同时有最近会话和示例。

## 刷新恢复

1. 完成一次变更（变更演示 → 批准 → 已回读验证）；
2. 刷新页面：消息、结论、最近一次变更卡片还在；
3. 卡片状态「已回读验证」，执行/回读摘要保留。

## 停止与重试

1. 发一条诊断，出现「停止」→ 点停止：状态「已停止」，提示后端可能仍在执行；
2. 停掉后端（8020）再发请求：出现错误条 + 「重试」；
3. 恢复后端点「重试」：请求成功、页面恢复。
   （这张错误截图是故意制造后端不可用，不是产品故障。）

## 审计

顶部「审计」→ 哈希链校验通过，能看到最近变更的 5 条链路。

## 本阶段不包含

- SSE（提交+等待+停止/重试）；
- 部署（阶段 4；本轮 D9 不部署）；
- 登录/多用户/真实设备执行。

## 验收

没问题回「验收通过」；交互/移动端要改直接说。
