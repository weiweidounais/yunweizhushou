# 阶段 2-1 验收：照着做

## 1. 启动

```bash
cd backend
.venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8020
```

浏览器打开 <http://127.0.0.1:8020/>。不要关这个终端窗口。

## 2. 依次问三个问题

点左侧「示例告警」里的按钮，或直接输入：

1. `core-sw-01 昨晚 22:00 开始丢包，什么原因？`
2. `db-prod-01 磁盘读延迟 240ms，数据库很慢，什么原因？`
3. `app-prod-02 CPU 95% 持续 20 分钟，怎么定位？`

每条等 6–10 秒（快速模式：预取上下文 + 一次交卷；没有流式输出）。

## 3. 每条看四件事

- 结论是否先给判断，再给证据；
- 根因假设是否带置信度、证据、反证；
- 处置建议是否标风险、是否需审批、回滚方式；
- 右侧「工具调用」是否能展开看到参数和结果。

## 4. 试一次「没有数据」

输入：`core-sw-01 光模块温度是多少？`

期望：它说指标里没有温度数据 / 不知道，而不是编一个数字。

## 5. 重启恢复

关掉启动窗口，再按第 1 步启动；刷新页面，之前的会话和消息应还在。

## 6. 打分

把三条样例的评分填到 `docs/evidence/阶段2-1/样例打分.md`。哪条「不能接受」，直接告诉我。

## 7. 验收

没问题就回「验收通过」；我运行 `bash kit.sh 通过 数据中心运维助理` 进入阶段 2-2（变更、审批、审计）。
