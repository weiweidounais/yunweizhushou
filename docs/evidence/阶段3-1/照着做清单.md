# 阶段 3-1 验收：照着做

## 启动

```bash
# 终端 1：后端
cd backend
.venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8020

# 终端 2：前端
cd frontend
npm run dev
```

打开 <http://localhost:3010/>。注意用 `localhost`，不要用 `127.0.0.1`（Next 开发态对来源有校验）。

## 看代表页

1. 打开后会自动创建会话并跳到 `/sessions/...`；
2. 左侧点「core-sw-01 昨晚 22:00 开始丢包」；
3. 点发送，等 6–10 秒：
   - 出现「结论」和影响面；
   - 点「展开根因、证据与处置建议」能看到证据、建议、回滚；
   - 右侧「工具调用」有 `get_incident_context`；
   - 底部显示模型、用时、tokens。
4. 刷新页面：消息和结论还在（本轮工具/用量不保留）。
5. 浏览器缩到 390 宽：示例变成左上角菜单抽屉，对话与输入框可用。

## 本阶段不包含

- SSE 流式输出；
