# 阶段 3-1 技术开发文档（前端：骨架 + 只读诊断）

> 配套：《前端适配声明》、PRD V3、前端手册第 22 节子阶段 1。
> 本阶段只做正式前端骨架和只读诊断代表页；变更审批/审计在 3-2，完整交互与移动端打磨在 3-3。

## 1. 本阶段目标

- 废弃阶段 2 的临时验收界面，建立正式 Next.js 前端。
- 交付可运行的工作台：会话创建、示例、只读诊断、结构化结论/证据、工具调用、刷新恢复。
- 桌面 1280/1440、平板 768、手机 390 基本可用。
- 通过 frontend lint/typecheck/test/build，并完成真实模型闭环。

## 2. 范围

### 本阶段包含

- Next.js 16.4.4 App Router + React 19.3 + TypeScript strict + Tailwind CSS 4；
- `proxy.ts` 把 `/api/*` 同源转发到后端 8020；
- 设计变量、AppHeader、工作台三栏布局、移动端示例抽屉；
- `/` 创建会话并跳转；`/sessions/[id]` 工作台；`/audit` 占位（3-2 开放）；
- `AssessmentCard`（结论/影响面，详情折叠）、`ToolCallList`、`Composer`、`SamplePanel`；
- 统一状态：idle/submitting/running/succeeded/failed；plan 状态映射留好扩展；
- 删除 `backend/static/index.html`，后端根路径改为 JSON；不另起平行界面；
- Vitest + Testing Library 单测；Lint/TypeScript/生产构建。

### 本阶段不包含

- 变更卡片、批准/拒绝、执行/回读、审计页（3-2）；
- SSE、取消/重试的完整交互、会话历史列表（3-3）；
- 登录、多用户、部署；
- 真实监控接入。

## 3. 用户流程

1. 打开 `http://localhost:3010/` → 自动创建会话 → 跳到 `/sessions/[id]`；
2. 左侧点示例（或输入问题）→ 发送；
3. 看到 running 状态和已用时间 → 6–10 秒后出现结论、影响面、展开详情、工具调用；
4. 刷新页面 → 按 URL 重新拉取会话，消息与结论恢复；
5. 手机打开 → 示例变抽屉，对话与输入框可用。

## 4. 页面状态矩阵

| 状态 | 触发 | 页面表现 |
| --- | --- | --- |
| idle | 新会话/无消息 | 空状态 + 示例入口 |
| submitting | 点击发送到请求发出 | 按钮禁用，禁止重复提交 |
| running | 请求进行中 | 显示「正在查指标…」+ 已用时间 |
| succeeded | 收到 ChatResponse | 结论卡片 + 工具调用 + 用量 |
| failed | 网络/后端错误 | 错误条 + 助手提示 + 可重试 |
| stale | 刷新后历史会话 | 重新拉取消息；本轮工具/用量不保留 |
| waiting_user | 3-2 变更待审批 | 3-2 实现 |
| disconnected | 断网/代理失败 | 错误条提示检查 8020 |

## 5. 接口契约

- `POST /api/sessions` → `SessionView`
- `GET /api/sessions/{id}` → `SessionView`（消息含 assessment）
- `POST /api/sessions/{id}/chat` → `ChatResponse`（reply/assessment/tool_calls/usage/elapsed_ms/change_plan?）
- `GET /api/demo/cases` → `{cases: DemoCase[]}`
- `GET /api/health`
- 错误统一 `{error:{code,message}}`；客户端归一化为 `ApiError`。
- 变更/审计接口已存在，3-2 接前端。

## 6. 实现方案

- `frontend/` 新建；`proxy.ts` 运行时转发，`BACKEND_URL` 从 `.env.local` 读取；
- `lib/api/client.ts` 集中请求与错误；`lib/api/types.ts` 类型；
- `lib/status.ts` 状态映射；`lib/format.ts` 时间/token/hash；
- `features/chat/Workbench.tsx` 组织会话、发送、刷新、响应式；
- 样式用 Tailwind 4 `@theme` 语义变量，主色青绿、页头深海军蓝、紧凑密度；
- 临时 HTML 删除；后端根路径返回前端地址 JSON；
- 单测覆盖状态映射、错误归一化、格式、AssessmentCard、Composer。

## 8. 风险与回退

- 前端 dev server 与后端端口分离；代理未配置时显示明确错误，不回退到临时界面；
- 无 SSE，长回答需等待；后续 3-3 视需要补；
- 刷新后本轮工具/用量不保留（会话消息保留）；3-3 再决定是否持久化；
- 如果 Next 构建/端口异常，回退到 `npm run dev` + `BACKEND_URL` 检查，不删除后端 API。
